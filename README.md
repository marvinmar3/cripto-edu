# cripto-edu
App de escritorio educativa donde un estudiante pueda probar y comparar tres familias de criptografía (sin llave, simétrica y asimétrica), usando una simulación de Alice (envía), Bob (recibe) y Eve (espía/ataca), para que entienda qué protege cada mecanismo y qué pasa cuando se usa mal o cuando alguien lo ataca.
